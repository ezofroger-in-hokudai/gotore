# 採用スタイル

`recording-controls.css` は #186 で合意したメモB案と終了操作のスタイルです。`app/layout.tsx` から既存v2.cssの後に読み込みます。

- メモ本文: 背景色・囲み枠・角丸なし、下の区切り線。既存の76px表示領域と編集・スクロールを維持。
- メモ入口: アイコン＋文字＋開閉方向。最小48pxの操作領域。
- 終了入口: グレーの枠。確認内は「まだ続ける」「今日のトレーニング終了」の2操作。
- 色は既存のテーマ変数を使い、ライト/ダーク/システム設定に追従。
- 320pxでは余白を縮め、種目名とセット一覧の表示量を保つ。文字拡大時は折り返す。

基準は `docs/design-system.md`。`docs/styles/current/` は過去の比較用スナップショットで、ここへコピーしません。独立HTMLはデザイン検討用、実装確認には `recording-style.spec.ts` と実画面の画像を使います。他画面の共通ボタン・入力等への展開は #186 の後続です。
