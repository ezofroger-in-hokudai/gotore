# 画面文言（#48）

2026-09-08のレビュー指示を適用する。通常画面は短い項目名とボタンを中心にし、重複する説明や装飾的な見出しを省く。「自分用メモ」は「メモ」、「トレーニング日」は「日付」とする。

共有範囲、下書き、入力補助、メモ等の説明は初回ガイドへまとめ、設定から再表示できる。入力条件はHTMLの制約と簡潔なエラーで示す。削除・退出・コピー等の確認は対象と動作を短く示す。失敗時は入力保持と再試行の動作を維持し、必要な次の操作だけを案内する。

既存の機能仕様にある画面上の説明文・長いラベルは本方針を優先する。権限・共有範囲・保存・競合の業務ルールは変更しない。種目のグループ固有化は今回のマージ完了後に相談し、現在の本人用リストを維持する。

## 追加整理（#50）

ログイン・通信・入力・競合エラーも、状態と次の操作を短く示す。通知で対象名を繰り返さず、同じ成功通知を二重表示しない。初回ガイドは共有範囲・入力補助・履歴保持の意味を残して短縮する。読み上げ用の識別ラベル、入力制約、失敗時の復帰処理は維持する。開発用READMEの詳しい手順は今回の対象に含めない。

見た目と操作領域は[デザインルール](design-system.md)に従う。文字数を減らすために文字サイズやタップ領域を縮めない。
