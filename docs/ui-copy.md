# 画面文言（#48）

2026-09-08のレビュー指示を適用する。通常画面は短い項目名とボタンを中心にし、重複する説明や装飾的な見出しを省く。「自分用メモ」は「メモ」、「トレーニング日」は「日付」とする。

共有範囲、下書き、入力補助、メモ等の説明は初回ガイドへまとめ、設定から再表示できる。入力条件はHTMLの制約と簡潔なエラーで示す。削除・退出・コピー等の確認は対象と動作を短く示す。失敗時は入力保持と再試行の動作を維持し、必要な次の操作だけを案内する。

既存の機能仕様にある画面上の説明文・長いラベルは本方針を優先する。権限・共有範囲・保存・競合の業務ルールは変更しない。種目のグループ固有化は今回のマージ完了後に相談し、現在の本人用リストを維持する。

## 追加整理（#50）

ログイン・通信・入力・競合エラーも、状態と次の操作を短く示す。通知で対象名を繰り返さず、同じ成功通知を二重表示しない。初回ガイドは共有範囲・入力補助・履歴保持の意味を残して短縮する。読み上げ用の識別ラベル、入力制約、失敗時の復帰処理は維持する。開発用READMEの詳しい手順は今回の対象に含めない。

見た目と操作領域は[デザインルール](design-system.md)に従う。文字数を減らすために文字サイズやタップ領域を縮めない。

## v2の記録画面

メモは通常の本文と同程度の表示とし、空の入力導線は「メモ」。種目・前回・今回という説明ラベルは表示せず、種目メモの下に前回の本文がある場合だけ置く。タッチして編集し、読み上げ用の識別名は維持する。画面の「推定1RM」は「1RM」、「このセットを保存」は「次のセットへ」、「トレーニングを終了」は「トレーニング終了」とする。


## 主要画面の棚卸し（#114）

ユーザーの画面整理継続指定に基づき、次の範囲を整理する。文字を小さくして残す方法は採らず、必要な説明だけを操作時に確認できるようにする。

| 画面 | 対象 | 扱い |
| --- | --- | --- |
| 共通ヘッダー | 「日々の積み重ねを、仲間と。」 | 装飾文のため削除。ロゴと主操作を保持 |
| ホーム | グループ作成/参加を促す説明 | グループ未所属の状態だけを短く示す。作成/参加手順は既存ガイド |
| ホーム/グループ | 「最初のセットを残しましょう」 | 空状態に続く呼びかけを削除 |
| ホーム/記録 | 開始時の共有範囲・本人だけのメモ | 操作前の判断に必要なため保持。#107の移設でも残す |
| 記録 | 未送信・同期中・競合・再送・終了待ち | データ状態と次操作に必要なため保持 |
| 記録 | メモの種目/前回/今回という重複ラベル | 既に本文中心へ整理済み。読み上げ名を維持 |
| グループ | LIVE/TODAY・人数・退出/除外 | 状態・権限・影響が分かる表示を保持 |
| 履歴 | セット数・時間・空状態・読み込み失敗 | 記録と未取得を区別するため保持。直近優先の構成は#112で対応 |
| カレンダー | 日別最高SCOREと色の凡例 | 何の点数か分かる最小表示を保持。説明は既存ガイド |
| 分析グラフ | 総負荷・推定RMの算式 | 「指標について」を開いたときだけ表示。開閉では通信しない |
| 分析ランキング | 現在共有されている記録を集計する説明 | 「共有済みの記録のみで集計」に短縮し常時表示 |
| 分析 | 比較不能・前期間・種目の選択条件 | 数字の意味が変わる条件のため保持。指標選択の構成は#113で対応 |
| 設定 | 「通知：準備中」 | 操作できない未提供項目のため削除。通知機能の実装は追加しない |
| 設定 | 目標取得/保存の状態・振動非対応の説明 | 設定の反映可否に必要なため保持 |
| Sheet/確認 | 削除・退出・コピー先・AI目標の確認 | 対象と結果・公開範囲を確認する文言を保持 |

API・DB・公開範囲・業務ルールは変更しない。指標説明は通常の文字サイズで表示し、開閉の操作領域を44px以上確保する。
