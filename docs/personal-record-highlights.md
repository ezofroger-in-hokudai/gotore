# 最高重量・最高RMの炎と赤字表示

2026-09-13の追加依頼（#134）。[v2仕様](gotore-v2-spec.md)の最高記録判定を、履歴・記録・グループ共有へ統一して表示する。初回・同値だけでは強調しない既存の判定を維持する。

- 種目名ごとに本人の保存済み全記録と比較する。主部位の異なる分類でも同名は同じ種目として扱う。
- 対象記録以外の最高値を基準にセット順で更新を判定し、現在も最高重量または最高RMを保つセットを強調する。初回・同値だけでは更新扱いにしない。重量とRMを別々に判定する。推定1RMの対象は既存どおり正の重量・1〜10回、表示と同じ小数1桁。
- 履歴一覧で該当記録に炎、履歴詳細・共有詳細で該当セットに炎と淡い赤の背景、該当する重量/RMの数値を赤字にする。グループの直近フィードは既存の追加保存時BEST条件を保ち、現在の最高値と一致する重量/RMを強調する。保存時の更新フラグがある場合は後から同値の記録が増えても最高値なら炎を保ち、上位更新があれば消す。
- 記録中は保存確定後の比較応答でセットを強調する。未送信や異なるrevisionの情報から炎を出さない。入力中の候補は既存の赤字のみ。
- 訂正・削除・取消や、他の記録による上位更新の後は最新の取得結果で再判定する。本人の履歴一覧・共有詳細の先読み/再確認を共用する。
- 共有側へ返すのは、その共有済み記録のセット位置と重量/RM別のフラグだけ。比較元の私的な記録・数値・メモは返さない。
- 閲覧一覧にセット位置を一括して含め、記録中は既存の比較応答へ含める。セットごとのHTTP取得を増やさない。履歴・共有の比較には既存のgotore_workout_statisticsを利用し、全履歴のセットJSONを繰り返し取得しない。新規DB・外部サービスは追加しない。
