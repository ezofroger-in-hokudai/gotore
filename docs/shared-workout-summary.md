# 共有記録の全体要約（#104）

週次#149で採用した定型要約をホーム・グループのフィードに追加する。

- 各カードが参照する共有記録1件の「3種目 · 9セット」を表示する。日全体や全履歴の合算ではない。同じ名前の種目は1種目として数え、セットは保存済みの全セットを数える。
- 最新セット・最高記録の表示と、タップした記録の詳細への導線を維持する。
- LIVE中もサーバーに保存済みの内容だけを集計する。終了・編集・削除時も既存のフィード更新に従う。
- 既存GET /groups/{id}/activityのfeedにsummary（exercise_count、set_count）を追加する。すでに取得している共有記録のexercisesから計算し、追加SQL・API・LLM呼び出しは行わない。
- 新旧配信の切替に備え、summaryのない応答では要約を表示せず、1種目と推測して補わない。
- 認可・共有解除・退会/除外・削除の条件と取得済み表示の保持/破棄は既存仕様を維持。本人メモ・目標・AIコメント・部位分類は含めない。

検証: 複数種目/セット、同名種目、空・0kg、保存後更新、終了、訂正/削除、非公開情報の非混入、DB要求数、詳細の遅延/失敗、モバイル3幅。
