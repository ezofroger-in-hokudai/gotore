対象はログイン／初回ガイド、ホーム、記録中の種目選択・セット入力・終了結果、履歴のカレンダー・グラフ・詳細、グループ一覧・詳細・作成・招待・参加・設定、アプリ設定、スタンプ操作。現行コード、採用済み設計資料、320/390/430pxのグループE2E、実データの共有・QR招待E2Eを照合した。実機での最終的な視認性・触感は別途確認が必要。以下は未採用の提案であり、画面は変更していない。

## 画面ごとの維持判断

- ログイン・初回ガイド: 初回導線は一方向で、今回の実操作テストでは迷いの原因を確認しなかった。説明を増やす提案はしない。
- ホーム: 数値ヘッダー、グループカード、独立したタイムライン絞り込み、浮遊STARTは採用案の役割が分かれている。カード全体タップによる展開は維持する。
- 記録中・終了結果: 種目選択からセット追加、終了まで通信応答を待たない既存の操作を維持する。入力フォームのサイズ変更は別Issueの判断範囲で、ここでは変更しない。
- 履歴: カレンダー、グラフ、記録詳細の機能は残す。初期入口だけ比較候補とする。
- グループ: 黒い既存カード、長押しドラッグ、最新記録／カレンダー／グラフ／設定のタブ順、QRパスを維持する。長押し中に「移動中」の文言やハンドルは戻さない。
- スタンプ: 6種類を最初から示し、絵文字への日本語の意味づけと通常時の送信中表示は戻さない。位置と操作の横断的な違いは既存監査で扱う。
- 設定: 行による一覧は整理されている。表示名の編集方式だけ共通化候補とし、外観・触覚・種目管理を一画面へ詰め込まない。
