# スタイル見本（#186）

まず [デモページ](index.html) で現行の部品を確認し、採用する形を決めます。
本フォルダは統一作業の出発点です。確定仕様の正本は引き続き [デザイン基準](../design-system.md) とし、今回その内容は変更していません。

## 開く

index.htmlをブラウザで開けます。ローカル配信する場合はリポジトリルートから：

```sh
python3 -m http.server 3186 --bind 127.0.0.1 --directory docs/styles
```

http://127.0.0.1:3186/ を開きます。認証やDBは不要です。

## 内容

- ボタン：主操作・補助・文字操作、無効/保存中、キーボードフォーカス。
- メモ：記録ヘッダー内の切替、下のメモ枠、編集と保存/閉じる。再読込で初期化するデモです。
- カード・スタンプ：通常の面、送信選択と取消、送信者の見本。新しい共通メニュー #184 は未実装です。
- 色・文字：ライト/ダークの実際のCSS変数値、見出しと本文。
- 320/390/430pxの見本幅とタップ領域の表示。

参照コミットは `07a397d`（PR #182の修正版。2026-09-19の撮影記録ではmain統合済み）。同コミットの `frontend/src/app/` からコピーし、layout.tsxと同じ順で読み込みます。旧作業ブランチ `3497301` のUIとは区別します。参照元は `session-screen.tsx`、`inline-memo.tsx`、スタンプ用CSSです。コピー元との差分なしを確認します。

スナップショットをアプリの新しい正本にしません。今後は合意した部品だけを共通スタイルへ移し、デモもその共通スタイルを参照する構成へ更新します。

## 現状の整理と決めること

| 対象 | 参照版の実装 | 統一前に決めること |
| --- | --- | --- |
| ボタン | v2基本形は角丸10px、最小高さ46px。画面側の追加指定あり | 用途ごとの形・高さ、48px操作領域との整合 |
| メモ切替/本文枠 | 角丸12px、黄色系。本文枠は高さ76px・内部スクロール | 配置・色・高さ・閉じる動作を共通にする範囲 |
| パネル | 角丸14px、余白18px | 記録カード等で共通にする形と余白 |
| スタンプ | pill高さ30px、操作領域は最小48px | 角丸や押下状態の共通化 |
| 色 | --accentと主ボタン用--ctaを分離。メモには固定色あり | ダークテーマでのメモ配色、赤の用途 |
| 文字 | v2本文14px、基本見出し22/16/14px。画面側の指定あり | 画面固有値と共通値の整理 |

旧基準には角丸原則0等の記述があります。上表は現状の記録であり、旧基準との矛盾を解消した採用案ではありません。現行の差分を隠したり自動的に基準へ戻したりせず、デモで採用を確認してから基準を更新します。

## 次の進め方

1. ボタンとメモの形・配置をデモで選ぶ。
2. 合意した値と状態を共通CSS/部品へ反映し、基準文書も更新する。
3. 代表画面から順に適用し、残る差分をIssueで追跡する。

独立見本のためアプリの保存/共有ロジックのテストは対象外。見本の開閉・メモ編集・テーマ・小画面・横はみ出しをブラウザで確認します。実機Safariと実アプリへの適用は後続です。

配置見本では、入力画面全体に指定されているビューポート高さだけをdemo.cssで解除しています。ボタンやメモの部品用スタイルはスナップショットを使用します。
