# 履歴グラフ・グループ集計

2026-09-11のユーザー合意を具体化する。Issue #97、関連 #14・#15。既存の履歴カレンダーとBEST仕様を維持し、実記録の推移を追加する。SCOREは #13 で算式を決めてから追加する。

## 表示

- 履歴は「記録」「グラフ」を切り替える。全種目では総負荷・セット数・活動日数、種目選択時は最高重量・最高推定1RMも表示する。
- 個人は1か月・3か月・1年・全期間。グループは週・月・全期間、過去期間にも移動できる。週は月曜日、日付はJSTの `performed_on` を使う。
- 日・週・月の集計粒度を切り替える。長期間は日別366日、週別156週までとし、それを超える粒度は表示せず月別を使用する。全期間でも描画量を制限する。
- グラフの点を選ぶと値と対象日付を表示。個人ではその集計期間の記録へ進める。空の重量・RMは0に置換せず、記録なしとして扱う。
- 最高重量・RMは記録のない期間をまたいで前後の実測点を直線でつなぐ。点・選択時の数値は実測だけとし、先頭/末尾の外挿や補間値の保存・集計は行わない。セット数・総負荷・活動量は未記録日の0を保持する（PR #98への追加依頼）。
- グループ詳細に「最新記録」「グラフ」「ランキング」を置く。グラフは総負荷・セット数・活動人数。
- ランキングは総負荷・セット数・活動日数、種目別最高重量・最高推定1RMと、それぞれの成長量（kg）・成長率（%）。同値は同順位（1、1、3）、記録なしは順位なし。順位のない初記録は一覧の後に表示する。

## 集計ルール

- 保存済みセットを対象とし、トレーニング中の保存済み記録も含む。空の開始セッションは除く。
- 総負荷は `Σ(重量kg × 回数)`。重量0もセット数・回数に含むが総負荷0。体重を補完しない。
- 種目名は保存済みの空白除去済み完全一致。削除した候補の過去記録も選べる。異なる種目の最高重量・RMを合算しない。
- 最高推定1RMは既存BESTと同じ（1回は実重量、2〜10回はEpley、小数1桁四捨五入、重量0・11回以上は対象外）。日/週/月の値はその期間の最大値で、通算自己ベストとは区別する。
- 活動日数は保存済みセットのある日数。グループ活動人数は期間内の記録者の重複を除く。
- 1か月は当月、3か月は当月を含む直近3か月、1年は当月を含む直近12か月。過去へ進むとその期間幅分移動する。
- 現在期間は今日まで。比較元は直前の同種の期間の先頭から同じ経過日数（元期間の末日を上限）とする。表示に比較日付を明記する。過去の完了期間は前の完了期間と比較する。
- 成長は期間内最大値と比較元最大値の差。比較元がない場合は「初記録」、比較元0の場合は増加量のみ、成長率は算出しない。全期間は比較元がないので成長順位を表示せず週/月で比較する。
- 個人は自分だけの記録も含む。グループは現在の参加者がそのグループへ共有している記録だけ。共有解除・退出・除外・記録削除は次の取得で反映し、再参加で過去共有を復元しない。

## 読み込みと整合性

- 既存PostgreSQLに記録×種目の集計を置く。記録の挿入・セット変更と同一トランザクションで当該記録のみ再計算し、削除は外部キーで連動する。ハートビートでは再計算しない。旧記録はmigrationで補完する。
- 閲覧APIはこの小さな集計から日別・期間別をまとめ、元の全履歴JSONを取得しない。共有判定は毎回元の記録・参加関係で行う。専用の別DBやワーカー基盤は導入しない。
- 1応答に全指標と表示可能な日/週/月の系列を含める。指標・粒度の切り替えは通信を待たない。
- キャッシュはログイン中の画面インスタンス内だけ、最大8応答・同時2通信。個人は60秒、グループは5秒を鮮度の目安とし、グループの表示中は5秒ごと・再訪/復帰時にも再取得する。選択中を優先し、よく使う期間・種目を先読みする。画面再訪はキャッシュを表示して必要なら更新する。
- 保存・訂正・削除・共有変更で無効化。非表示・ログアウト時は不要な通信を停止する。権限エラーを受けた集計はキャッシュから消す。ブラウザ永続保存はしない。
- グループは表示中の更新を行い、キャッシュを永続的な閲覧権限とは扱わない。通信中も操作を止めず、未取得時は同じ高さの読み込み枠、取得失敗時は再試行を表示する。

## 検証

日付境界・RMと丸め・未記録・0重量・同順位・成長の比較元、既存記録の移行、保存/訂正/削除/取り消し、非参加者/非共有/退出、キャッシュの再利用/無効化/中止/遅延応答を検証する。E2Eで履歴とグループの切り替え、グラフから記録への導線を確認する。実測をPRに記載する。

## API

- `GET /api/analytics?period=month&offset=0&exercise=種目名`。periodはweek/month/quarter/year/all、exercise省略は全種目。
- `GET /api/groups/{group_id}/analytics` は同じ選択とグループ権限確認。返却は期間/比較元、候補、全指標合計、表示可能な全粒度の系列、ランキング。
- `GET /api/workouts?date_from=YYYY-MM-DD&date_to=YYYY-MM-DD` は本人の記録を両端含む期間で50件ずつ取得する。2日付を必ず組で渡し、performed_on指定との併用はしない。
