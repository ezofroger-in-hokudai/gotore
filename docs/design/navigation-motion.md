# 画面遷移の動き

2026-09-29、ユーザーが比較プレビューのB「控えめな横移動」を採用した。[採用した動きの固定プレビュー](../../frontend/public/previews/navigation-motion-adopted.html)を実装・画面確認の基準にする。

## 採用した動き

- 進むと新しい画面内容が右から18px入り、戻ると左から18px入る。180ms、`cubic-bezier(.2,.8,.2,1)`。元の内容のスナップショットは重ねず、新しい内容を不透明なまま横移動させる。2026-09-29の実機フィードバックで、旧画面を78%の濃さで残す動きは残像が強いとして取りやめた。
- ホーム・グループ・履歴・設定の切替、記録・結果・編集画面への移動、グループ一覧と詳細などの画面状態の切替に適用する。下部タブも同じB案とする。
- ヘッダーと下部ナビは固定し、主な画面内容だけを動かす。既存の画面構成、戻る履歴、シート開閉、未保存入力は変えない。
- ブラウザの戻る・進むと左端スワイプでも履歴に対応する方向へ動く。連続操作では最後の画面と履歴を正とする。
- 端末の「動きを減らす」設定では即時に切り替える。View Transitions APIのないブラウザでは新しい内容だけを同じ距離・時間で動かす。

## 比較した案

| 案 | 進む・戻る | 時間 | 印象 |
| --- | --- | --- | --- |
| A 短いフェード | どちらも同じ淡い切替 | 160ms | 動きが目立たず、タブにも合わせやすい |
| B 控えめな横移動 | 進むと右から18px、戻ると左から18px。元画面は重ねない | 180ms | 戻る方向が分かる |
| C 少し大きい横移動 | 入る画面が42px、元画面が22px逆へ動く | 220ms | Bより移動方向が明確 |
| D 画面を押し出す | 入る画面が端から画面幅いっぱい移動し、元画面を押し出す | 280ms | 画面の前後関係が強い |
| E 奥行きのある横移動 | 入る画面が48px、元画面が16px動き、軽く拡縮する | 240ms | 手前と奥の差が出る |
| F 横移動＋フェード | 入る画面が28px動きながら現れ、元画面が14px動きながら消える | 210ms | 横移動を柔らかく見せる |
| G 軽い拡大縮小 | 進むと入る画面が少し拡大、戻ると少し縮小 | 200ms | 位置移動なしで前後を表す |
| H 縦に浮く | 入る画面が24px上下に動く | 190ms | 下部からの操作に近い印象 |

[比較プレビュー](../../frontend/public/previews/navigation-motion-options.html)は経緯として残す。A・C〜Hは今回採用しない。両プレビューの表示値と画面内容は動きの確認用サンプルであり、既存画面の新しい仕様ではない。
