# 設定画面の設計

共通の色・余白・操作領域は[デザインルール](../design-system.md)に従う。この資料は設定画面固有の採用判断を記録する。

## ログアウト

- サポート項目の末尾に置き、文字色を危険操作と同じ赤にする。
- 行を押しただけではログアウトせず、`ログアウト` 見出しの確認シートを開く。
- 確認シートには短い確認文と `キャンセル`、赤い `ログアウト` を置く。
- `キャンセル` と `ログアウト` は同じ8pxの角丸・同じ高さにし、片方だけ形を変えない。
- `キャンセル` は設定画面へ戻し、確定した場合だけローカルセッションを破棄する。
- 処理中は確認シートを閉じたり重複実行したりできないようにする。失敗時はログイン状態を維持し、既存のエラー表示で再試行できるようにする。

## プロフィールの取得と編集（#278）

- 設定一覧、表示名編集、画像編集は、ログイン中のユーザーの同じ取得結果を使う。直後の画面往復・編集を開くだけでは追加取得しない。
- 名前・画像はWorkspace内のメモリだけに保持する。ログアウト・ユーザー切替で破棄し、本人記録の端末スナップショットへ画像を加えない。
- 初回は必要な取得と失敗時の再試行を維持。前回の取得開始から60秒以上経過した再訪は、表示済みデータを保持して背景で再確認する。設定を見ていない間の定期取得は行わない。
- 保存・削除の成功結果を一覧へ即反映し、取り直しが終わるまで表示を待たせない。古い背景応答で新しい保存値を戻さない。Authだけ成功した名前変更は、現行の共有同期の再試行を維持する。
- 設定フォーム・目安箱の下書きの寿命と閉じ方は従来どおり。取得結果の保持によって未送信の入力を永続化しない。

## 触覚設定と種目フォーム（#275・#272）

- 触覚フィードバックは設定一覧のスイッチで直接オン/オフする。専用シートは開かず、一覧に現在値と、セット保存時の振動・対応端末/ブラウザで利用可能という短い説明を置く。端末への保存とユーザー別の設定キーを維持する。
- 種目追加と部位編集のキャンセルは、保存/追加の下に同じ `secondary full` ボタンを置く。文言・角丸・枠・文字・高さを揃え、保存対象と送信中の取消制限を維持する。
- 2026-10-01の継続依頼により採用。その他の設定行・初回ガイドは現在の採用案を使う。変更前後は `docs/images/remaining-fixes/README.md` に記録する。

## 設定一覧内の直接操作と文字階層（#293）

- 表示名は専用シートを開かず、グループ名変更と同じ行内編集にする。右側の現在値を押すと同じ行に入力欄と右寄せの `キャンセル` / `決定` を表示し、入力欄へ直ちにフォーカスして、もう一度押さずに文字入力できるようにする。保存には既存のAuth更新・プロフィール同期・部分成功時の再試行を使い、成功後は通常表示へ戻す。キャンセルは未保存入力を破棄して取得済みの値へ戻す。
- 外観は設定一覧に `ライト` / `ダーク` / `自動` の3択を常時表示し、選択中を赤い文字と枠で示す。既存の `light` / `dark` / `system` とユーザー別端末保存を変えない。
- 触覚フィードバックは既存の一覧スイッチを維持する。通知は種類、開始タイミング、音、振動、Pushを含むため、概要行から詳細シートを開く。種目はユーザー管理の一覧が長く追加・編集・削除を含むため、管理シートを維持する。プロフィール画像も画像選択・保存・削除を含むためシートを維持する。
- `›` はプロフィール画像、種目、通知、目安箱、使い方のように別UIへ進む行だけに置く。表示名、外観、触覚のように一覧内で完結する操作には置かない。
- 設定タイトルは28px/700、節見出しは13px/600、項目名は15px/400、現在値は14px/400、補足は13pxを基準とし、色は共通の `--text` / `--muted` を使う。通常の文字は太字にせず、画面タイトルと節見出しだけで階層を付ける。白〜薄灰背景、白い角丸カード、赤アクセント、下部ナビ、STARTは変更しない。
- 320/390/430pxで横方向にはみ出さず、外観の各選択肢は44px以上、通常の設定行は56px以上の高さを確保する。インライン編集は必要な縦スクロールを許容し、下部ナビやSTARTの構造を変更しない。

## 共通ボトムシートの閉じ方（#293）

- 閉じることができる通常のシートは、文字の `閉じる` を置かず、右上の `×`、Escape/ブラウザ戻る、暗い背景のタップ、上部見出し領域の下スワイプ、ドラッグハンドルの下スワイプで閉じる。`×` には読み上げ名「閉じる」を残す。
- 背景操作は外側で開始して外側で終了した主ポインターだけを対象とし、シート内タップ、スクロール、右クリックを閉じる操作にしない。下スワイプは縦方向が横方向より大きく80px以上動いた場合に閉じる。
- 送信中のログアウト確認や、別機能で明示的に閉じる操作をロックしているシートは従来どおり閉じない。設定のプロフィール画像・種目は今回の指定に従い、未保存状態でも背景タップと下スワイプで閉じる。
