# グループ画面の設計

2026-09-26からの検討資料。現在の採用案は既存の黒いグループカードを縦に並べる一覧型。実装済みの共有・権限・履歴集計を変えず、グループホームの構成と参加・招待の見せ方を定める。

## 今回確定した共通条件

- 下部ナビの「グループ」は、選択中グループの有無にかかわらずグループホームへ着地する。個別詳細はホーム内でグループを選んで開く。
- グループホームから、所属グループの確認、作成、参加、表示順の変更へ進める。
- 表示順はホームのカードとグループ切替に共用する現在の本人・ブラウザ単位の順序を維持する。グループカードを長押ししてドラッグし、順番を直接変更する。短いタップは詳細表示に使う。
- 長押し中はカードを指に追従させ、移動先のカードをずらして挿入位置を見せる。移動ハンドルや「移動中」の可視文言は追加しない。
- 詳細ではグループ単位の総負荷、セット数、活動人数、履歴を確認できる。カレンダー・グラフ・記録一覧は個人履歴と共通の部品・集計規則を使う。
- 既存の黒48pxヘッダー、選択トラック、記録カード、スタンプ、フローティングSTART、下部ナビ、色と余白を再利用する。
- 招待リンク・QRは発行から7日間、複数人が参加できる。参加前にグループ名・人数・メンバーを確認して再検証する。

## A・E再検討で決まったこと

- グループカードには移動ハンドルや「›」を常時表示しない。カードを長押ししてドラッグすると表示順を変更できる。短いタップは個別詳細への移動に使い、一覧には「長押しドラッグで表示順を変更」と案内する。
- 個別グループ設定にはグループ名、メンバー、退出を置き、全グループ共通の表示順は置かない。オーナー変更はメンバー一覧の各行から行う。
- 招待方法はリンク共有とQRコードの2つとし、12桁コードの直接入力は画面に出さない。
- 招待画面は `メンバーを招待`、対象グループ名、初期表示したQR、`リンクを共有` で構成する。「リンクをコピー」は共有と目的が重なるため並べない。
- 招待QRは黒い招待パスに載せ、赤いアクセントと中央のバーベルを上げるウォンバットで識別できるようにする。中央の重ね表示に合わせてQRは高い誤り訂正レベルを使い、読み取りやすい白余白を残す。
- リンク共有にOSの共有機能がない場合は同じボタンでコピーする。HTTPの実機確認で新しいクリップボードAPIが使えない場合も旧式のコピーを試し、両方できない場合は選択できるリンクを表示する。
- グループに所属する全メンバーが招待リンクとQRコードを表示・共有できる。
- 招待リンクとQRは発行から7日間、複数人の参加に使える。新しい招待を発行しても、以前のリンクは各自の期限まで有効とする。ただし、発行者がグループを抜けた場合とグループ削除時は失効する。
- 期限切れの招待からは参加できず、グループメンバーが新しい招待を発行して共有する。
- オーナーだけがメンバーをグループから退出させる操作と、グループ自体の削除を行える。一般メンバーは参加中のグループから自分で抜けられる。
- オーナーが退出する前に、設定から現在のメンバーへオーナー権限を移譲する。
- 参加前にグループ名とメンバー数を確認してから参加する既存の安全策は、リンクとQRのどちらでも維持する。
- 初回利用者が招待URLを開いた場合は、ログイン後も参加確認を優先し、通常の使い方ガイドは次の通常起動まで後回しにする。招待URLを開いたまま非表示の起動画面で参加シートを生成しない。

招待画面で表示するリンクとQRコードは同じ招待を表す。リンク・QRから開いた参加確認画面には、対象グループ名とメンバー数を表示する。招待は期限で失効し、参加人数では失効しない。2026-09-27に複数人利用のための追加migrationを実装した。

## 一覧・詳細・参加の接続

- グループ一覧は既存の黒いグループカードを使う。カード内の「›」と移動ハンドルは表示しない。
- 個別詳細の先頭は、一覧で選んだカードを拡張したグループ概要とする。名称、LIVE、活動人数、セット数、総負荷、参加者アイコンを共通にし、一覧と詳細を別の画面体系に見せない。
- 招待する側の画面と参加する側の画面を混在させない。個別詳細から「メンバーを招待」へ進み、一覧の「グループに参加」からはQR読み取りへ進む。
- 招待リンクまたはQRからアプリを開いた場合は、一覧の参加入口を経由せず、対象グループの参加確認へ直接進む。
- 既に参加済みの人が有効な招待リンクを開き直した場合は、確認を繰り返さず、そのグループの詳細へ進む。参加後のホーム往復・ブラウザバックでも招待確認を再表示しない。
- 招待画面ではグループカードを再掲せず、対象グループ名だけを表示する。「グループなら誰でも招待できます」のような権限説明は置かない。

### 参加前の詳細表示（A案を採用）

2026-09-28の実機確認で、人数だけのボトムシートではグループを判断しづらいと分かった。A案の1ページ表示を採用する。有効な招待リンクを持つログイン済みの人に限り、グループ名・人数・メンバーの表示名と役割を見せる。写真、活動日時、記録、管理操作は参加前には出さない。参加ボタンでは招待の有効性を再検証する。

- 採用: 黒い概要に名称・文字アバター・人数を置き、下に既存のメンバー行を並べる。多人数時はフェードから展開できる。下部ナビの上に参加ボタンを置き、その下に「参加後の記録から共有されます」と表示する。参加後は通常のグループ詳細へ進む。
- 不採用: B案の白い詳細、および人数だけのボトムシート。
- 採用プレビュー: `frontend/public/previews/group-join-detail-adopted.html`。比較時のA/Bは `frontend/public/previews/group-join-detail-options.html`。

## 設定タブ

- 通常設定を「グループ情報」「メンバー管理」のまとまりに分け、白い面、境界線、角丸は既存の設定・カード部品へ合わせる。
- グループ名は項目名と現在値を表示する。オーナーが現在値をタップすると同じ行で入力・「決定」・キャンセルに切り替え、別フォームを下に増やさない。一般メンバーには値だけを表示する。「メンバー全員に表示されます」のように見れば分かる補足は置かない。
- 別端末で変更されたグループ名は、画面の再読み込み後に反映されれば十分とする。即時同期やタブ切替時の自動再取得は要件にしない。
- オーナー自身と一般メンバーを同じメンバー一覧内に置く。オーナー本人には役割ラベルを表示し、一般メンバーには「退出させる」を表示する。
- メンバー一覧は最終トレーニング日時の新しい順にする。同時刻の場合は現在の一覧順を保ち、記録のないメンバーは末尾へ置く。活動日時も各行に小さく表示し、順序の理由が分かるようにする。オーナーも活動日時に従って並べる。
- オーナーのメンバー行メニューから「オーナーにする」または「退出させる」を選べる。オーナー移譲は確認してから確定する。
- メンバーが多い場合はホームのトレーニング記録カードと同じ展開方式を使う。初期高さを固定し、カード下部全体に暗めのフェードを重ね、フェードまたはカード内の操作以外をタップして全員を展開する。展開後に再度タップすると縮小する。「すべてのメンバー」という別の行や画面は設けない。
- 閉じた状態は3人をちょうど切るのではなく、4人目のアイコンが半分見える約3.5行分の高さにし、続きと展開操作の存在を視覚的に示す。
- オーナーが一般メンバーの所属を終了させる操作は「退出させる」と表示する。「外す」は使用しない。

- 招待は詳細上部の共通管理ボタンにあるため、設定タブ内へ重複して置かない。
- グループ削除は通常設定から離した最下部の危険操作とする。「グループを削除」を押したら同じ画面上の小さな確認シートを開き、対象グループ名と「キャンセル」「削除する」を表示する。取り消せない旨の説明は置かない。削除時はグループ内の全共有記録をグループから取り除き、本人の個人履歴・他グループ共有は保持する。
- 一般メンバーには削除・他のメンバーを退出させる操作を表示せず、同じ最下部に「グループから抜ける」を表示する。オーナーにも同じ「グループから抜ける」を表示し、オーナーが退出可能であることを見えるようにする。設定画面には説明を置かず、オーナーが退出操作を押した先のシートで、先に別メンバーへオーナー権限を移譲する必要があることを説明し、「メンバー一覧へ」から移譲操作へ進める。

### 招待画面のメンバー表示（検討中）

既存の招待パス・QR・リンク共有を残し、招待画面で現在のメンバーも確認できる案を比較する。新たなグループカードは再掲せず、個別詳細にあるアバターと人数、または設定にあるメンバー行の見た目を使う。作成直後の固定高シートでは作成者1人から始まること、招待操作が下へ押し出されないことを確認してから採用案を決める。招待画面にオーナー変更・退出などの管理操作は持ち込まない。
- カレンダーとグラフは、今後設計する履歴画面の共通部品をそのまま使う。今回の仮表示を確定デザインとしない。

### 全画面プレビューの適用範囲

- 一覧、最新記録、設定、作成、招待、参加確認の確定済み操作を反映する。
- カレンダーとグラフは今後作る履歴画面の共通部品に合わせる予定のため、統合プレビューでは遷移確認用の仮表示とする。
- QRはサンプル画像であり、プレビューから本物の招待リンクは発行しない。実装では7日間有効で複数人が使える招待リンクを表示する。
- 退会時は本人の個人履歴を保持し、対象グループへの共有だけを解除する。グループ削除時は全メンバーのグループ共有を解除し、個人履歴・他グループ共有は保持する。
- グループ削除確認シートは設定内の危険操作から開き、確定すると一覧へ戻る。
- グループ名の変更はオーナーだけに表示し、一般メンバーはグループ名を閲覧のみとする。オーナーにはグループ削除と退出の両方を表示し、退出前にメンバーへのオーナー移譲を案内する。
