アプリへ接続する前の提案。架空の種目リストを使用し、ネットワーク通信・DB保存なし。A/Bの部位切替・検索との組み合わせ・種目選択・部位編集と390px表示をChromiumで操作確認した。各アプリ枠は390px幅。実機の操作感は未検証。

Aを推奨。通常は一覧から直接選択でき、必要な場合だけ部位で絞る。部位設定は別シートに集約し、通常の記録画面では主な部位・補助部位を小さく表示する。Bは部位の発見を優先し、一覧を切り替えるための戻る操作が増える。

今回のトレーニングを短い行へまとめて再選択する導線も提案に含む（関連#66）。2026-09-13にユーザーが画面を含めてA案を承認。今回の実装へ採用した。
