# 実画面の機能案内

架空のテストアカウントで、実アプリに表示された赤枠・矢印・説明を撮影。トレーニング開始・保存・グループ参加はしていない。

| 対象 | 画面 |
| --- | --- |
| START | [320px](start-320.png) / [390px](start-390.png) / [430px](start-430.png) |
| 種目管理 | [設定](exercises.png) |
| 部位カレンダー | [履歴](calendar.png) |
| グラフ | [指標の切替](graph.png) |
| グループ | [作成・参加](groups.png) |
| 案内の再表示 | [使い方](replay.png) |
| ダーク | [使い方](dark.png) |
| 文字200% | [使い方](large-text.png) |

文字拡大で説明が長くなる場合は案内内をスクロールできる。赤枠は対象の実際の位置に追従する。通常の画面操作も可能で、モーダル操作中は案内を隠す。
