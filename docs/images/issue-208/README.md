# Issue #208 記録の送信失敗時

390 × 844px の記録画面で、ベンチプレスを70kg × 8回のセットとして端末に保存し、セット送信 PATCH を失敗させて撮影した。同じモックデータ、端末保存済み、サーバー未反映の状態で比較した。

- [修正前](before.png): 入力欄の下に「未送信・端末に保持」と手動の「再送」を表示する。
- [修正後](after.png): セットが一覧へ即時反映され、通常の入力画面だけを表示する。次の種目へ移動した後、オンライン復帰で自動再送できることをE2Eで確認した。

撮影は `frontend/tests/e2e/session-background-send.spec.ts` に保存処理を含め、修正前のアプリで失敗、修正後のアプリで成功させて行った。
