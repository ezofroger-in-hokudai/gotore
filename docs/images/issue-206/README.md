# Issue #206 シート外タップ

設定の「外観」を開いた390 × 844pxの画面で、背景上端の同じ位置を1回タップした後を撮影した。

- [修正前](before.png): 背景をタップしてもシートが開いたまま。
- [修正後](after.png): シートが閉じて設定へ戻る。

`frontend/tests/e2e/sheet-backdrop.spec.ts`で修正前の失敗と修正後の成功を確認した。320/390/430pxとタッチ操作でも背景を閉じられる。シート内から外へドラッグした場合は閉じず、ブラウザの戻るは設定からホームへ進む。入力を失う可能性のある表示名フォームは背景タップで閉じない。
