# 履歴グラフとグループ集計

Issue #97。390×844pxのChromiumで撮影したページ全体画像。値と名前は `frontend/tests/e2e/analytics.spec.ts` のUI確認用データで、実利用者の記録ではない。

- [個人の総負荷](personal-volume.png)
- [種目別最高重量](personal-weight.png)
- [グループランキング](group-ranking.png)
- [グループの推移](group-graph.png)

折れ線で日・週・月の推移を表示し、点のタップまたは下のスライダーで期間を選ぶ。個人グラフの「この期間の記録を見る」から対象期間の履歴へ進める。指標と集計単位は同じ応答に含めて通信なしで切り替える。

## 計測

2026-09-11、ローカル開発環境、Chromium、通信に1.2秒の人工遅延。先読み・取得済みのデータを用いた最終画面で、指標変更から2回の描画フレームまで15.6ms、キャッシュ済み期間の再訪から表示確認まで62.2ms。各1回の操作計測で、実端末や本番ネットワークの保証値ではない。ページの実行エラーなし。

DB計測の条件・再現コマンドは [読み込み性能](../../loading-performance.md#履歴グラフの集計-97) を参照。実データの共有境界は別途ローカルSupabaseのE2Eで確認している。
