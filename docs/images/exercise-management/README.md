名前検索と部位フィルターは取得済み候補に適用する。設定・記録・履歴編集で候補を共用し、保存成功時には応答から表示を更新する。長い一覧はSheet内でスクロールする。画面幅・追加/削除・失敗・競合・未取得・権限喪失の検証はexercise-management.spec.tsと既存の種目管理E2Eを参照。

API/DBと過去の記録名は変更しない。OS実機のキーボード操作は未確認。仕様は[種目の部位保存・選択](../../exercise-body-parts.md#開始前の管理と保存結果の即時反映148)。
