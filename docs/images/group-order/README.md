# グループ表示順（#118）

ホームのカードを長押しすると浮き上がり、そのまま左右に動かせる。端まで動かすと自動スクロールし、隣のカードが移動先を空ける。指を離すとこのブラウザの本人専用順序を保存する。

- [カードを移動中・390px](drag-390.png)
- 保存後: [320px](320.png) / [390px](390.png) / [430px](430.png)
- Linux / Chromium、高さ844px。`frontend/tests/e2e/group-order.spec.ts`で撮影した架空グループの画面。実ユーザーデータは含まない。
- 「画面テスト部」を2番目へ移動し、選択は同じグループを保持した状態。
- グループ一覧の長押し/「並べ替え」からはシートを開き、上下ボタン/キーボードでも変更できる。
- タッチ操作はChromiumのタッチイベントで検証する。実機Safari・PWAの操作感は未検証。
