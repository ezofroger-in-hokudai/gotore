# 操作調査の不具合修正画面

ローカル実Auth/DBの調査用ユーザー、Chromium390×844。アプリ6160063で確認。STARTの左右座標の追加修正前の画面だが、以下3機能の表示はその追加修正で変更しない。本番データ・実機PWAではない。

- [ダークの編集中行（#268）](dark-edit-after.png): 重量・回数・RMと編集対象の背景を確認。
- [オーナー変更確認（#270）](owner-confirm-after.png): グループ・対象・本人の権限変更を表示。この画面でPATCHは0件、キャンセルして権限変更は行っていない。
- [人体図の取得失敗（#279）](body-failure-after.png): 端末複製なしでsnapshot/活動GETを503にし、同じタブに失敗と再試行を表示。記録なしの文言は0件。

ダーク行の画面確認では調査用ユーザーに20kg×10の1セットを追加し、終了まで実施。未処理pageerrorなし。スクリプトで終了ボタンの旧名称を指定した停止は、現行の「トレーニング終了」へ修正して再開しており、アプリ不具合とは扱わない。
