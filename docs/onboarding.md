# 初回利用ガイド（#18）

画面文言は2026-09-08の[簡略化方針](ui-copy.md)を優先する。説明は初回ガイドに集約し、以下の業務ルールを維持する。

2026-09-08のユーザー指示「一般的に判断できる仕様は実装してよい」に基づく追加範囲。登録方法・入力条件・共有ルールは [standard-v0.1-scope.md](standard-v0.1-scope.md) を維持する。

- ログイン後、ホーム上部に3段階の案内をインラインで表示する。グループの作成／招待参加、種目・セット入力、共有先の明示と個人記録の違いを説明する。
- 「次へ」「戻る」で読み進め、「スキップ」「はじめる」で閉じる。参加・記録・共有先変更・下書き更新は自動で行わない。案内表示中も通常のナビゲーションと操作を妨げない。
- スキップと完了はどちらも表示済み。localStorageへユーザーIDと版番号で分けて保存し、同じブラウザの再読み込み・再ログインでは自動再表示しない。別ユーザー・別ブラウザ・保存削除後は表示する。
- 設定画面の「使い方ガイドを開く」から、何度でも最初から再表示できる。表示名の取得成否には依存しない。
- 保存領域が使えない場合も操作を継続し、その場では閉じる。次回表示の可能性を案内する。サーバーへの既読保存や端末間同期は行わない。
- スマートフォン幅・キーボードで操作できる。ステップ変更と再表示時は案内見出しへフォーカスを移す。

検証: 初回・スキップ・完了・再読み込み・再ログイン・設定からの再表示・ユーザー分離・保存失敗、既存の記録共有をブラウザで確認する。画像はPRから参照できるように保存する。

## 実画面への案内（#151、2026-09-14の追加依頼）

初回案内の3段階インライン表示を、実際の対象を囲む赤枠・矢印と短い説明に置き換える。START、設定の種目管理、履歴カレンダー、グラフ、グループ作成/参加、設定からの再表示の6段階とする。通常画面の説明文は増やさない。

- 次へ/戻るで該当する閲覧画面に移動し、対象までスクロールする。赤枠は実要素の位置に追従する。実データがなくても常設の操作対象を案内できる。
- トレーニング開始、記録保存、グループ参加/作成は自動実行しない。対象の実ボタンはユーザー自身が操作できる。操作により対象が隠れた場合は矢印を消し、案内を再表示する導線を出す。モーダル操作中は案内を隠し、モーダルを閉じたら戻す。
- スキップ・Escape・完了で閉じられる。案内は非モーダルで通常操作を妨げない。次へ/戻るの説明見出しへフォーカスを移す。
- v2の既読キーは維持する。既読の人へ自動で再表示せず、設定の使い方から再度開く。ユーザー分離とストレージ失敗時の扱いは従来通り。
- 案内専用のAPI・画像/動画・外部ライブラリを追加しない。画面移動時は既存の取得・キャッシュを利用する。進行中のトレーニングや入力中の値を変更しない。
